# Linear Systems and Signals — Python Solutions

This project aims to collect and consolidate Python solutions to all examples and exercises in *Linear Systems and Signals* by B. P. Lathi and Roger Green.

The solutions combine three complementary approaches:

- **Numerical methods** with NumPy to compute and verify results.
- **Symbolic methods** with SymPy to derive exact expressions and explore mathematical relationships.
- **Graphical solutions** with Matplotlib to visualize signals, systems, and the concepts behind each problem.

Solutions are organized in Jupyter notebooks by chapter, bringing together problem statements, relevant formulas, Python implementations, and visualizations. The goal is to build a comprehensive study companion that connects mathematical reasoning with practical computation.

## Progress

This is a work in progress. Examples and exercises are being added as the study of the book advances; complete coverage is the project's goal.
